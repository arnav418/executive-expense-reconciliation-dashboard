# 📊 Executive Expense & Reconciliation Dashboard

An interactive **Microsoft Excel dashboard** designed to monitor executive expenses, approval status, reimbursement progress, and reconciliation exceptions.

The project transforms raw expense records into a structured dashboard that provides a quick overview of financial activity and highlights items requiring attention.

---

## 📌 Project Overview

Managing employee and executive expenses can become difficult when expense records, approval information, reimbursement status, and exceptions are spread across different records.

This project provides a centralized Excel-based solution to:

- Track total expenses
- Monitor approved and pending amounts
- Track reimbursed amounts
- Analyze expenses by category
- Monitor approval status
- Monitor reimbursement status
- Identify reconciliation exceptions
- Present key information through an interactive dashboard

---

## 🎯 Objectives

The main objectives of this project are:

- Build a structured expense management workbook
- Automate financial calculations using Excel formulas
- Create a management-friendly dashboard
- Track approval and reimbursement workflows
- Identify potential reconciliation issues
- Present financial information through clear visualizations

---

## 🔄 Reconciliation

The reconciliation section is used to identify expenses that require additional attention.

The workbook tracks different expense conditions and categorizes them into relevant exceptions, helping users quickly identify outstanding issues.

This makes it easier to distinguish between:

**Normal Expenses → Approved → Reimbursed**

and

**Exceptions → Pending / Missing Information / Duplicate Records**

## 📁 Workbook Structure

The workbook is organized into the following sheets:

### 1. Expense Data
Contains the underlying expense records used by the dashboard and reconciliation process.

### 2. Reconciliation
Used to evaluate expense records and identify reconciliation-related exceptions.

### 3. Dashboard
Provides the visual summary of expenses, approval status, reimbursement status, and exceptions.

### 4. Lists
Contains supporting lists used within the workbook.

## 🚀 How to Use

1. Download the Excel workbook.
2. Open the `Expense Data` sheet.
3. Add or update expense records.
4. Review the `Reconciliation` sheet for exceptions.
5. Open the `Dashboard` sheet.
6. Review the updated KPIs, charts, and exception summary.

The dashboard is connected to the underlying expense data, allowing the summary information to update when the source data changes.
